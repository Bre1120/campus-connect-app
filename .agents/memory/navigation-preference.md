The user requested navigation in a footer instead of the header-side panel.

**Why:** This is the user's requested layout, not an incidental generated design choice.

**How to apply:** Preserve footer navigation in future app-shell redesigns unless the user asks for a different layout. Keep all app and account destinations accessible on small screens, and reserve content space so the footer does not cover controls.
